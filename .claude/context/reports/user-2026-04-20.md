Oneri: **Free plan icin bundled credits** (aylik $X Anthropic usage, Stripe invoice ile geri tahsil) + settings'te "How to get Anthropic key" link + gercek key test call (Faz 11'da TODO olarak isaretlenmis: `packages/api/src/modules/integration/router.ts:223`).

   - Clarification loop 3 round x her round 15-30sn = 90sn
   - Preview okuma: 60sn
   - Creating: 15sn
   - **API key setup**: 3-5 dakika (Anthropic'e git, aka yeni hesap)
   - **Ilk run**: 30-60 saniye
   - Gercek: **10 dakika degil, 20+ dakika** (Marcus/Priya zaman tutsa). Vaad test edilemeyen kadardan kaçınılmalı veya "10 dakikada bir pipeline kurman, ilk run'un 30 saniye" seklinde daha spesifik.

Oneri: tek yol, bir default + "skip to freeform" opsiyonu.

5. **Free -> Paid middle yok + trial yok** (Marcus, Priya, Sarah). Free = 10 run / 1 company / TikTok+LinkedIn. Pro = 100 run / 5 company / all channels / HubSpot / $49. Arada **$15-19 "Solo"** yok.
